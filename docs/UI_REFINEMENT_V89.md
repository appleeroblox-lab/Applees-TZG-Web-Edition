# Chat, map and terrain refinements v89

Global chat defaults to 300 × 225 CSS pixels, constrained by the viewport. Settings → Global Chat Size scales its width/height from 70% to 140% and persists independently on this device. Friend/group messages use small text-only bubbles, with avatars and display names outside. Images remain outside bubbles, and image-only [Screenshot]/[Image]/[Photo]/[GIF] placeholders are hidden. Existing image viewing, edit/delete/report and voice controls remain available.

Message/detail ellipses use a centered SVG to avoid font baseline shifts. Search and edit buttons use flex alignment. Profile join information moves slightly left/down. Username editing opens in its own modal with the existing validation and 24-hour cooldown. The XP label is centered in both axes.

Universe Map is centered, retains active gameplay, and uses deterministic schematic orbit spacing to separate primary bodies. Moons are arranged around their parent; All systems lays out systems in separate tiles, with each body present once. Background star fields depend on the selected system; they are illustrative. The list fills remaining sidebar height, and mobile hides redundant quick tabs to increase list space. Help now explains launch, leaving an atmosphere, selecting other systems, locking a destination, warp confirmation/costs, landing, routes, controls, resources, chat and settings.

Terrain Decorations is a per-device setting for grass and ground detail. A shared 512 × 128 generated atlas contains grass/sand/snow/rock detail, selected per vertex using the biome/body. It reuses one material shader program and adds no terrain draw calls. Grass has no per-frame animation, collision or individual scene objects: triangles join existing visible-chunk scenery meshes. Mobile/compatibility budgets cap candidate patches at 64 per chunk, with 3 blades per patch. Roads, launch pads and settlement footprints stay clear. Trees remain available for harvesting. Run moves left beside/above the thumbstick; Jump sits on the right, opposite it, honoring the existing size setting.

Validation: desktop and 844 × 390 browser layouts; separate username dialog; image-only and image+text posts; centered map and scrolling catalog; real WebGL compilation/render of terrain shader and batched grass (7 draw calls in the fixture). Unit checks cover all-body uniqueness, stable map spacing, shared texture/uniform toggling, terrain types, retained scenery, mobile grass bounds and device persistence. Existing social, account, language/device, scenery and desktop/gameplay suites pass. Mobile checks use emulated viewports; physical-device frame rate was not measured.

No database migration is needed for v89. Existing v88 verified-directory/resource-XP features still require SQL013 if it has not been applied.
