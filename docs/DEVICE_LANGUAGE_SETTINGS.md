# Device preferences and offline languages (v84)
System Language and Chat Translation Language are independent, device-saved choices: English, Burmese, French, Japanese and Thai. Game-styled selectors replace native dropdowns. UI dictionaries ship with the game; the game title and player content remain unchanged. Missing UI entries fall back to English.

Show Chat Translation Button enables a manual Translate action in message options for global, friend and group messages. No automatic translation or translation API remains. A curated phrasebook translates recognized phrases only; unknown messages retain their originals and show an unavailable notice. Burmese bro is ဟျောင့်. Original message/report/edit data stays intact.

Inbox ordering uses authorized latest-message IDs with a deterministic room-ID tie break before drawing. Preview requests update text without moving rows. Buttons wrap growing text and navigation rows have gaps.

No SQL migration is required. Device preference and social regression suites pass; browser fixtures cover desktop and landscape mobile sizes.

## v85 interface and media update

Each select opens its own body-mounted modal dialog in the browser top layer. Language selectors use the same mechanism, so a previously opened Account panel cannot capture a Settings selector. Native select values and change handlers remain the source of truth. Interface localization now includes the Universe Map, map filters, flight panels, keyboard/touch control labels, selection dialogs and developer navigation; body names, proper titles, account identities and player content stay literal.

Manual chat translation replaces only the visible message body. The original server text remains available through Show original and stays unchanged for edits and reports. A faint Translated label is localized independently. Translations survive the social polling redraw and clear when the target language changes, translation controls are disabled or the account signs out. The offline phrasebook includes Hello Space Explorers! and can translate multiple recognized sentences in a long message. This is not a general machine translator: an unknown sentence remains original and gets an unavailable notice. There is no translation API, network fallback or generated guess.

The combined Emoji / GIF picker has separate tab contents, compact styled search and a preview-before-send flow. GIF search uses Wikimedia Commons' public search/imageinfo API; only CC0/public-domain GIFs within the existing 1 MB / 1024-pixel limits are offered. Provider failures show a retry message; uploaded GIFs still work. Provider response URLs and file bytes are validated. Searching contacts Wikimedia, not a translation service. No provider key or new database schema is required.

Social voice messages use an in-game player: play/pause, timeline, elapsed/duration display and Voice into Text. Hold the recording control (pointer, touch or Space/Enter) and release to create a local preview. Sending is a separate action. Releasing while microphone permission is pending requests a stop immediately after permission completes. Pointer cancellation, blur, closing or navigating out cancel capture and stop microphone tracks.

Voice into Text uses browser on-device SpeechRecognition with the recorded audio track routed through Web Audio. It explicitly requires local recognition and a supported installed language model; it never silently falls back to microphone capture or a cloud transcription endpoint. A downloadable model offers an explicit Install voice language action. Unsupported browsers/languages show an unavailable notice. This cannot guarantee speech-to-text on every phone. Results stay in the viewer and do not automatically send as chat. No live voice-call service was added.
